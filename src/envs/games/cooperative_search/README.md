# Cooperative Search Mock

## 空间与运动

- 世界坐标单位为公里，地图大小为 `300×300 km`；游戏仍使用 `500×500 px` 绘制地图，物理距离与显示像素按比例换算。
- 概率数据库为 `100×100`，每格边长3公里。
- 四架无人机固定出生在地图左上角 `30×30 km` 正方形的四个顶点：`(0,0)`、`(30,0)`、`(0,30)`、`(30,30)`；目标与动态威胁位置仍按局随机生成。
- `fixed_speed_mps=100`，`step_interval_secs=30`；游戏按 `speed×time/1000` 得到每步3公里。
- 动作仅选择12档航向。相邻步骤最多改变30°；正常动作必须保留一条最多180°连续转向的回图路径，异常边缘状态只开放单个应急转向，保证掩码永不全0。
- 三个动态威胁同样作为Agent使用12档航向及相同动作掩码；三者共享一套在独立环境中训练完成的QMIX/RNN策略，正式场景中作为固定Agent运行。速度80米/秒（每步2.4公里），探测/击杀半径30公里，45公里内进入预警范围。
- 分阶段训练使用 `dynamic_threats_enabled` 启停威胁。关闭时仍保留三个Agent与集中状态槽位，但威胁不移动、不渲染、不探测且相关输入归零，以保证课程间模型可直接继承。

## 共享数据库

四架无人机直接写入同一张概率图和访问图。传感器半径40公里，探测率为0.8、误警率为0.2；正负观测通过距离加权的log-odds贝叶斯公式累计融合，证据从传感器中心向边缘平滑衰减，概率限制在0.1～0.9，避免重复扫描后饱和为纯0或纯1。每架无人机每步只产生一次传感器级布尔报告：范围内存在目标时按0.8报告侦察到，范围内没有目标时按0.2误报；不输出目标坐标或编号。

训练在第1局终局先输出一张共享概率热力图，之后每200局输出一张；图片使用 `#130d68 20% → #3b94a0 80% → #3cd33e 100%` 连续渐变，0%为蓝色、100%为绿色，不叠加目标真实位置。

概率数据库始终共享；科目不计算通信观察或奖励，渲染阶段也不再计算或绘制无人机间通信连线。

无人机进入动态威胁30公里探测圈后立即被吃掉，从活动Agent和游戏画面移除；训练配置中每架损失产生 `-6.0` 团队死亡惩罚。四架无人机全部损失时立即截断本局。威胁与无人机初始至少间隔60公里，避免开局即处于预警或击杀区。无人机统一绘制为绿色三角，动态威胁绘制为红色圆；概率达到90%的真实目标格绘制小绿圈，空白误标格绘制小红叉，游戏与概率图片采用相同标记。侧栏仅汇总显示已确认目标数量，不公开目标坐标或编号。

共享访问图中的9平方公里网格第一次被任一无人机传感器覆盖时，团队获得0.00082探索奖励；整图奖励上限为8.2分。同一步多机覆盖同一网格、后续重复覆盖和reset初始覆盖均不重复计奖。

概率图首次把一个网格推到概率上限0.9（态势中按100%标记）时结算核心奖励：真实目标每个加1分，空白格扣0.3分，同一目标或错误格一局只结算一次。目标概率增量和十目标终局大奖励已取消；全部目标达到概率上限后只负责成功终止。

每架无人机读取自身周围 `11×11` 的概率、访问、友机位置和动态威胁四个独立通道。每个观察格聚合 `2×2` 个3公里概率格，因此输入维度不变，物理视野约为 `66×66 km`。威胁通道在45公里内显示连续危险势场：30公里内为最高危险，30～45公里平滑衰减。QMIX Mixer读取由完整共享图按2倍池化得到的 `50×50` 视图以及四架无人机、三个威胁的飞行状态，但同样不读取目标真值。

固定威胁的原始观察为34维：自身归一化坐标和航向4维，以及十个目标按距离排序后的归一化距离、相对方位正弦和余弦30维。该观察由正式环境中的 `get_threat_obs` 唯一定义，威胁专训环境直接导入复用；威胁策略不读取无人机信息。

## 随机演示

```bash
PYTHONPATH=src python src/envs/games/cooperative_search/demo.py --seed 7 --max-steps 500
```

按 `V` 显示或隐藏传感器范围，按 `Esc` 退出。游戏画面不会显示隐藏目标。

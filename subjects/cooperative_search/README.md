# 共享概率图协同目标搜索 QMIX / MAPPO 训练

本训练科目是一个面向后续仿真接入的 Mock：四架无人机在 `300×300 km` 连续区域内协同搜索隐藏目标，同时提供 QMIX 和 MAPPO 两套集中训练、分散执行配置。

## 场景规格

- 四架学习无人机固定出生在地图左上角 `30×30 km` 正方形的四个顶点，即 `(0,0)`、`(30,0)`、`(0,30)`、`(30,30)`；三个固定QMIX策略动态威胁和默认十个隐藏目标仍按局随机生成。
- 所有课程阶段的网络维度保持一致。QMIX和MAPPO均依次训练无威胁搜索与带威胁闪躲两个阶段。
- 动态威胁也是环境Agent，使用12档航向和与无人机相同的±30°转向及边界动作掩码；三者共享一套在独立环境中训练完成的QMIX/RNN网络，在正式搜索中作为固定Agent运行，不参与无人机Learner更新。固定速度 `80 m/s`，每步移动 `2.4 km`，探测半径 `30 km`。
- 共享 `100×100` 概率数据库，每格表示 `3×3 km`。
- 传感器半径 `40 km`，探测率为0.8、误警率为0.2。每架无人机每步只产生一次传感器级布尔报告；范围内有目标时按0.8报告侦察到，范围内无目标时整次扫描按0.2误报。概率图仍按各网格距离加权的正负证据进行log-odds贝叶斯更新：证据强度从传感器中心向边缘平滑衰减，未搜索格保持0.5，置信度限制在0.1～0.9，避免重复扫描后退化成纯0或纯1。
- 概率数据库始终共享；科目不再设计通信观察、奖励或游戏连线。
- 固定速度 `100 m/s`，每个决策步 `30 s`，Mock 中每步移动 `3 km`。
- 十二档航向，每档 `30°`；首步任意选择，之后只允许保持或左右转一档。边界动作必须保留一条最多180°连续转向的回图路径，并使用单动作应急转向保证掩码永不全0。
- 每局最多600步。QMIX训练 `2001` 局无威胁搜索和 `2505` 局带威胁闪躲，共 `4506` 局；盘中评估每200局执行一次。

## 网络输入与奖励

### 单机局部观察

每架学习无人机获得一份以自身为中心的局部观察。底层概率数据库为 `100×100`，每个观察格聚合 `2×2` 个底层格，因此一个观察格对应 `6×6 km`，`11×11` 窗口覆盖约 `66×66 km`。

| 输入项 | 形状 | 维度 | 数值及业务含义 |
|---|---:|---:|---|
| 共享概率图 | `11×11` | 121 | 四机共享；未获得证据为0.5，贝叶斯概率限制在0.1～0.9；`2×2`个3公里底层格取均值 |
| 共享访问图 | `11×11` | 121 | 访问次数先进行对数归一化，再按`2×2`个3公里底层格取均值 |
| 友机位置图 | `11×11` | 121 | 其他存活无人机所在观察格为1，其余为0；同格多机仍为1 |
| 动态威胁势场 | `11×11` | 121 | 30公里内为1，30～45公里连续衰减，45公里外为0；搜索课程全0 |
| 自身归一化坐标 | `2` | 2 | `x / map_width`、`y / map_height` |
| 本步侦察标志 | `1` | 1 | 每步一次传感器级报告：范围内有目标按0.8为1，无目标按0.2误报为1 |
| **环境原始观察合计** |  | **487** | `11×11×4 + 2 + 1 = 487` |

QMIX和MAPPO共享的Agent RNN在环境原始观察后追加：

| 框架追加项 | 形状 | 维度 | 说明 |
|---|---:|---:|---|
| 上一步动作one-hot | `12` | 12 | 对应12个离散航向动作 |
| 智能体编号one-hot | `4` | 4 | 区分四架共享网络参数的学习无人机 |
| **框架追加合计** |  | **16** | `12 + 4 = 16` |
| **Agent RNN最终输入** |  | **503** | `487 + 12 + 4 = 503` |

死亡无人机的原始观察置为全0。Agent RNN隐藏状态为128维，四架无人机共享网络参数。

### 固定威胁观察

正式搜索环境和威胁专训环境共同调用同一个 `get_threat_obs` 实现。三个威胁共享一套QMIX/RNN策略，只读取十个目标的距离与相对方位，不读取任何无人机位置、方位或探测状态。

| 输入项 | 形状 | 维度 | 数值及业务含义 |
|---|---:|---:|---|
| 自身归一化坐标 | `2` | 2 | `x / map_width`、`y / map_height` |
| 自身航向 | `2` | 2 | 当前航向的`sin、cos`；首步尚无航向时均为0 |
| 十个目标距离与相对方位 | `10×3` | 30 | 目标按当前距离从近到远排序；每个目标依次输入地图对角线归一化距离、相对方位`sin、cos` |
| **环境原始观察合计** |  | **34** | `4 + 10×3 = 34` |
| 上一步动作one-hot | `12` | 12 | 与正式搜索相同的12档航向 |
| 威胁编号one-hot | `3` | 3 | 区分三个共享网络参数的威胁 |
| **威胁RNN最终输入** |  | **49** | `34 + 12 + 3 = 49` |

威胁专训QMIX的集中状态为32维：十个目标的归一化二维坐标20维，加三个威胁的归一化坐标与航向12维。正式搜索中的固定威胁只做分散推理，不读取该专训集中状态。

### 集中训练状态

集中状态仅在训练时供QMIX Mixer或MAPPO集中式Critic使用，分散执行时单机无法读取。

| 状态项 | 形状 | 维度 | 处理方式 |
|---|---:|---:|---|
| 完整共享概率图 | `50×50` | 2500 | `100×100`底层概率图按`2×2`均值池化 |
| 完整共享访问图 | `50×50` | 2500 | `100×100`访问图按`2×2`均值池化 |
| 四架无人机飞行状态 | `4×4` | 16 | 每架为归一化`x、y`和航向`sin、cos` |
| 三个动态威胁飞行状态 | `3×4` | 12 | 每个为归一化`x、y`和航向`sin、cos` |
| **集中状态合计** |  | **5028** | `50×50×2 + (4+3)×4 = 5028` |

死亡无人机槽位和关闭课程中的威胁槽位置0。集中状态不包含目标坐标、目标编号或目标真值。

### 动作输入

| 项目 | 设计 |
|---|---|
| 动作空间 | 12个离散航向，每档30° |
| 首步动作 | 允许选择全部边界可行航向 |
| 后续转向 | 只允许保持、左转30°或右转30° |
| 边界约束 | 转向约束后继续叠加边界可行性掩码 |
| 动态威胁 | 使用相同动作空间和掩码，由预训练固定QMIX/RNN策略控制，不参与主任务学习 |

### 团队奖励

第`t`步团队奖励由六部分构成：

```text
r_team(t) = r_correct(t) + r_false(t) + r_explore(t) + r_frontier(t) + r_death(t) + r_empty(t)
```

变量定义：

| 变量 | 含义 |
|---|---|
| `C_t` | 本步首次达到概率上限0.9的真实目标数量 |
| `S(n)` | 确认n个目标后的累计正确标记奖励；`S(0)=0`，`S(10)=20`，且`S(8)=10`（半程比0.8） |
| `F_t` | 本步首次达到概率上限0.9的空白误标网格数量 |
| `E_t` | 本步按无人机稳定顺序结算后，首次获得传感器证据的网格数量 |
| `P_t` | 存活无人机向最近未探索网格靠近量的均值，除以单步3公里后限制到`[-1, 1]` |
| `D_t` | 本步被动态威胁击杀的无人机数量 |
| `Z_t` | 同一步内按无人机顺序结算后，覆盖已确认空白格的“格-无人机事件”总数；先覆盖者记探索，后覆盖者记重复 |
| `U` | 单机传感器覆盖格数的固定理论上限；当前3公里网格、40公里半径下为`27×27=729` |
| `Q_t` | 重复空白搜索归一化比例，`Q_t=Z_t/(4×U)`，范围为`[0, 1]` |

奖励分量：

| 奖励项 | 公式 | 当前含义 |
|---|---|---|
| 正确标记奖励 | `r_correct(t) = S(n_t) - S(n_{t-1})` | 十目标累计总额20分；确认到80%进度时累计仅得一半，后段目标边际奖励更大 |
| 错误标记惩罚 | `r_false(t) = -0.3 × F_t` | 每个首次达到0.9的空白误标格扣0.3分 |
| 首次探索奖励 | `r_explore(t) = 0.00082 × E_t` | 每个首次覆盖网格加0.00082分 |
| 未探索边界势能 | `r_frontier(t) = 0.03 × P_t` | 朝最近未探索网格移动为正、远离为负，单步团队奖励限制在-0.03～0.03 |
| 无人机死亡惩罚 | `r_death(t) = -6.0 × D_t` | 每损失一架无人机扣6分 |
| 重复空白搜索惩罚 | `r_empty(t) = -(15 / 600) × Q_t` | 只惩罚传感器内已观测且达到概率下限0.1的空白格；单步最多扣0.025分 |

完整单步奖励公式：

```text
r_team(t) = [S(n_t) - S(n_{t-1})] - 0.3 × F_t + 0.00082 × E_t + 0.03 × P_t - 6.0 × D_t - (15 / 600) × Q_t
```

奖励结算规则：

- 0.9是概率数据库上限，在态势图中表示100%标记；正确目标和错误网格整局都只结算一次，概率回落后再次升高不会重复奖励或扣分。
- 正确标记奖励使用指数增长累计曲线：配置`correct_detection_reward_total=20`与`correct_detection_reward_half_life_ratio=0.8`，使前8个目标合计10分、后2个目标合计10分，鼓励搜完剩余目标。
- 概率达到0.9时统一进行确认、奖励和可视化：真实目标格画小绿圈并首次加分，空白误标格画小红叉并首次扣分。
- 首次探索奖励按 `3×3 km` 底层格结算，整图上限为 `100×100×0.00082=8.2` 分；同一步内按无人机名称顺序结算足迹，先覆盖者拿探索分，后覆盖同一格者若该格已是确认空白则计入重复搜索。
- 重复空白搜索惩罚与探索奖励共用同一步顺序结算；惩罚使用固定上限`4×729=2916`归一化。配置项`revisited_empty_penalty_episode_limit=15`使单步理论扣分上限为`15/600=0.025`，用于与首次探索奖励和未探索方向势能共同形成均势；未探索的0.5概率格不扣分。
- 未探索边界势能使用本步动作前的共享访问图作为固定参照，按四机平均计算；完整朝向未探索区域移动最多加0.03分，完整背离最多扣0.03分，原地或沿等距线移动接近0分。
- 取消原目标概率增量奖励、通信塑形、十目标全部完成时的终局大奖励，以及固定的每目标`1.5`平坦正确标记奖励。
- 十个真实目标全部达到0.9时成功终止，但不额外加分；达到600步或四架无人机全部死亡时截断。
- 环境把`r_team(t)`平分给四个学习无人机，每架返回`r_team(t) / 4`；三个固定威胁在正式环境中的奖励恒为0，框架聚合后恢复完整团队奖励。
- 目标坐标和编号不进入单机观察、集中状态或公开日志。环境内部真值仅用于奖励判定，以及把达到90%的可视化标记分类为绿圈或红叉，不直接绘制目标坐标。


## 输出与启动

训练默认不保存共享概率热力图；评估开启后每100局保存一张。热力图使用 `#130d68 20% → #3b94a0 80% → #3cd33e 100%` 连续渐变，0%为蓝色，100%为绿色：

`artifacts/results/cooperative_search/probability_{task_id}_{阶段名}_episode_{局数}.png`

QMIX和MAPPO两个阶段均使用简短标识 `search`（搜索）和 `evade`（闪躲）。各阶段均从第1局开始编号并独立输出，不会覆盖其他阶段的同局号图片。

课程防遗忘（框架 rehearsal）：`search` 结束时用 `rehearsal_archive_ratio=0.25` + `even_span` 冻结一阶段轨迹；进入 `evade` 后 `rehearsal_sample_ratio=0.25` 让每个 off-policy batch 固定回放 25% 搜索样本。`clear_replay_buffer` 只清理 active 环，不会删掉 rehearsal。

串行训练入口：

```bash
python -m portal.serial_stage_train -f subjects/cooperative_search/cooperative_search_qmix.toml
python -m portal.serial_stage_train -f subjects/cooperative_search/cooperative_search_qmix_partitions.toml
python -m portal.serial_stage_train -f subjects/cooperative_search/cooperative_search_mappo.toml
```

当前态势表征正式科目保留两个四分区配置：`cooperative_search_qmix_partitions.toml`
使用独立组轨迹抽样，`cooperative_search_qmix_partitions_bundled.toml` 使用同局多组捆绑抽样。
两者都将每组无人机限制在各自固定的 `300×300 km` 职责区内：动作掩码按职责区筛选落点及连续转弯路径，推进时也拦截越区位移；威胁继续全图游走。训练、盘中评估和正式评估共用此约束。
二者均为600×600公里、16架无人机、8个固定威胁、40个目标，并加载6f548e77威胁模型。

Torch RPC分布式训练入口：

```bash
# 先独立训练威胁策略
./scripts/start_torch_rpc_distributed.sh subjects/cooperative_search/cooperative_search_threat_qmix.toml

# 威胁模型就位后再启动正式搜索
./scripts/start_torch_rpc_distributed.sh subjects/cooperative_search/cooperative_search_qmix.toml
./scripts/start_torch_rpc_distributed.sh subjects/cooperative_search/cooperative_search_mappo.toml
```

威胁专训运行2001局，阶段名为`avoid_targets`。其奖励只围绕远离十个目标设计：向远离最近目标方向移动获得距离势能，进入30～45公里预警带连续扣分，进入30公里范围每架、每步额外扣1分。训练完成后选定威胁策略文件，并放置为 `artifacts/models/cooperative_search_threat/fixed_dynamic_threats_agent_net.pth`；正式QMIX和MAPPO配置均从这个稳定路径加载固定Agent。

QMIX课程由 `search` 和 `evade` 两个阶段组成。`search`训练2001局，关闭动态威胁，学习率为`2e-4`且每局学习2次；`evade`训练2505局，继承搜索阶段模型并启用动态威胁，学习率降为`1e-4`且每局学习1次。两个阶段各自建立1000局近期偏置回放池。

MAPPO仍从头训练2601局搜索阶段，再以该阶段毕业模型启动3601局闪躲阶段；使用严格on-policy步游标，每累计3600个新鲜环境步执行一次PPO更新。MAPPO搜索阶段使用`lr=5e-5`、`entropy_coef=0.005`和8轮PPO优化，闪躲阶段使用`lr=5e-5`、`entropy_coef=0.005`和4轮优化。输出目录分别为`cooperative_search`和`cooperative_search_mappo`。
